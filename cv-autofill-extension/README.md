# CV AutoFill v2

إضافة محلية لمراجعة نماذج التوظيف وتعبئتها والتحقق من نتائجها. بيانات السيرة تعمل داخل سياق الإضافة المعزول، والمرفقات تُحمّل عند الحاجة.

## التشغيل

1. من `chrome://extensions` فعّل وضع المطور واختر **Load unpacked** ثم هذا المجلد.
2. إذا كانت الإضافة مثبتة مسبقًا، اضغط تحديث الإضافة ثم حدّث صفحة النموذج يدويًا.
3. استخدم **فحص الخطة** من popup أو لوحة الصفحة. راجع الإجابات، واستبعد أي حقل أو عدّل إجابة هذه العملية.
4. اضغط **تعبئة والتحقق**. popup يتعامل مع الصفحة وإطاراتها الداخلية؛ لوحة الصفحة تخص نموذج الإطار الرئيسي.
5. **إيقاف** يلغي الانتظار والإجراءات اللاحقة. التأثير الذي حدث بالفعل لا يمكن التراجع عنه تلقائيًا.

لا تنفذ fill الإرسال النهائي. أزرار الإرسال في لوحة الإضافة إجراءات منفصلة وصريحة، ويُفحص النموذج قبل تنفيذها. تبقى أسئلة الفحص غير المعروفة والموافقات والاشتراكات للمراجعة.

## الملف الشخصي والمرفقات

افتح **الملف الشخصي والمرفقات** من popup:

- عدّل البيانات، ومنها المعدل وتاريخ بدء التدريب، ثم احفظ وحدّث صفحة النموذج.
- اختر CV أو خطاب الجامعة أو شهادة بصيغة PDF حتى 10MB. تُحفظ الملفات داخل الإضافة، والسيرة الأصلية متاحة افتراضيًا.
- راجع القواعد المعتمدة واحذفها أو صدّرها.

`data.js` هو مرجع القيم الأصلية. لم تُغيّر الحقائق الشخصية عند نقلها إلى v2. تُحفظ التعديلات من الإعدادات كتجاوزات محلية داخل Chrome. إذا كان تاريخ بدء التدريب قديمًا، تظهر حالة تحتاج مراجعة بدل افتراض تاريخ جديد.

## التعلم

بعد كل تشغيل تُحفظ عدادات النجاح والفجوات المنظفة داخل الإضافة. الربط الذي نجح بقاعدة منصة موثوقة يُتعلم تلقائيًا كمفتاح للسيرة، دون نسخ القيمة الشخصية. القواعد المعتمدة صراحةً تسبق هذا الربط والقواعد العامة. لا تراقب الإضافة الكتابة لتخزينها تلقائيًا. بعد إدخال إجابة لحقل غير معروف، يمكن اعتمادها صراحةً من أدوات القواعد في لوحة الإضافة. القاعدة مرتبطة بالموقع والاستمارة ونوع الحقل والتلميحات المطابقة تمامًا.

لا تُعتمد كلمات المرور أو OTP أو رموز الجلسات أو حقول الهوية والمعلومات المالية. التعلم لا يشغّل التعبئة كأثر جانبي.

## واجهة الوكيل

واجهة الصفحة العامة أصبحت غير متزامنة، وتعيد بيانات تشخيصية دون الملف الشخصي أو محتوى PDF:

```js
await window.__CV_AGENT.inspect();
await window.__CV_AGENT.plan();
await window.__CV_AGENT.getButtons();
await window.__CV_AGENT.validate();
```

لتشغيل التعبئة عبر واجهة الصفحة، فعّل الجلسة أولًا من popup أو بنقرة فعلية على زر التعبئة في لوحة الإضافة:

```js
const result = await window.__CV_AGENT.fill({ delay: 35 });
// status, success, verifiedFields, failedActions, blockedActions, cancelled
await window.__CV_AGENT.cancel();
```

الجلسة مرتبطة بعنوان الصفحة الحالي. قبل التفعيل تُعاد `ACTIVATE_FROM_EXTENSION_FIRST`. اعتماد قواعد أو فتح بيانات أو إرسال الطلب عبر رسائل الصفحة يُرفض بـ `TRUSTED_CHANNEL_REQUIRED`. الموقع والوكيل يتشاركان سياق الصفحة؛ وجود window.__CV_AGENT لا يثبت هوية المتصل.

واجهة المحرك الكاملة موجودة في سياق الإضافة `ISOLATED` للوكيل الذي يملك قناة موثوقة إلى ذلك السياق. أمثلة للاستخدام هناك:

```js
await __CV_AGENT.learn('#referral', 'إجابة أكدها المستخدم');
await __CV_AGENT.fill();
// الإرسال لا يدخل ضمن fill:
await __CV_AGENT.clickButton('button-id', { confirmSubmit: true });
const sanitized = __CV_AGENT.captureFixture();
```

تستمر أسماء plan/play/fill/inspect وحقول total/filled للتوافق. أسماء الأزرار الثابتة في getButtons هي buttonId؛ الأرقام تُحسب بعد تصفية الأزرار المخفية.

`standalone-autofill.js` مولّد من `page-bridge.js`، ويحتاج الإضافة المثبتة. لا يحتوي نسخة أخرى من المحرك أو بيانات شخصية أو PDF:

```js
await window.__runCoopAutofill({ delay: 35 });
```

## الملفات والتطوير

```text
data.js                    القيم الشخصية الأصلية فقط
core/field-catalog.js       المعاني والقواعد العامة
core/profile.js            اللغة والتنسيق وإعدادات الملف
core/matching.js           مطابقة مشتركة للقوائم والخيارات
adapters/                  اكتشاف المنصات وقواعدها
core/scanner.js            وصف الحقول ومجموعات الإجابات
core/planner.js            إنشاء الإجراءات دون النقر أو استهلاك روابط
core/runner.js             الطابور والتزامن والإلغاء والنتائج
drivers/                   التفاعل مع أنواع الحقول ورفع الملفات
core/validation.js         فحص النموذج والحفظ الفرعي
core/controller.js         الجلسة وAPI وتغيرات الصفحة
core/dashboard.js          مراجعة الخطة وعرض الحالة
ui.css                     تنسيق الواجهة المعزولة بـ Shadow DOM
options.*                  إعدادات البيانات والمرفقات والقواعد
background.js              مدخل العامل القائم على الأحداث
scripts/dev/server.cjs     أدوات تطوير منفصلة ومحمية
docs/                      المعمارية وسجل التجارب والتحديث
```

ملفات engine.js وcontent.js وui.js وsite-rules.js مداخل توافق صغيرة. عند إضافة منصة، أضف adapter يحدد host وقواعد تربط المحددات بمفاتيح profile، ثم أضفه في ترتيب manifest. لا تنسخ قيم الهاتف أو الاسم داخل adapter.

البناء لا يحتاج حزمًا خارجية:

```powershell
node cv-autofill-extension/scripts/build.cjs
node test-suite/run-tests.js
node test-suite/browser-tests.cjs
```

من هذا المجلد توجد أيضًا `npm run build` و`npm test` و`npm run test:browser`. اختبارات المتصفح تستخدم Playwright بالإصدار المثبت في package-lock؛ يمكن تنفيذ `npm ci` لتجهيز بيئة مستقلة. في مساحة العمل الحالية يستطيع الاختبار استخدام النسخة الموجودة في الأرشيف دون تنزيل جديد.

اختبارات Chrome تثبّت الإضافة داخل ملف مؤقت، وتحجب جميع HTTP(S) إلا النماذج المحلية التي تجيبها في الذاكرة. لا تنفذ تقديمًا على ATS حي. نتائج آخر تشغيل في `../test-suite/browser-results.json`.

للمختبر اليدوي:

```powershell
node test-suite/serve.cjs
```

افتح `http://127.0.0.1:8091` مع الإضافة المثبتة. المختبر يعرض العينات ولا يحقن بيانات السيرة في MAIN. اكتشاف المنصات على عنوان المختبر يكون عامًا؛ اختبارات المتصفح الآلية تحاكي عناوين المنصات لاختبار adapters.

## أدوات التطوير

التشغيل العادي يحتفظ بإحصاءات التحسن محليًا. لتفعيل التحديث التلقائي والتقاط العينات المنظفة شغّل وضع التطوير:

```powershell
npm --prefix cv-autofill-extension run dev
```

الخادم على `127.0.0.1:8989` فقط، وينشئ رمز الاتصال تلقائيًا؛ يمكن تحديد CV_DEV_TOKEN اختياريًا. طلبات الكتابة تحتاج `Authorization: Bearer ...`، وحد الحجم 1MB، والأصول غير المعتمدة تُرفض. endpoint `/save-fixture` يستقبل عينة منزوعة البيانات صراحةً؛ لا ترسل HTML خامًا. السجل يقبل بيانات تشخيصية محدودة بدل قيم الحقول. logger.js مدخل قديم يستعمل الكود نفسه على منفذ 3456.

بعد تحميل هذا الإصدار من الإضافة اضغط فحص مرة لتتصل بوضع التطوير. التغييرات الصحيحة تُطبق تلقائيًا على الإضافة والنماذج الخالية المرتبطة؛ التحديث ينتظر عند وجود تنفيذ أو بيانات غير مرسلة. لا يُعاد تحميل تبويب غير متعلق بالإضافة. إيقاف الخادم يعطل هذا المسار.

## حدود التحقق

التحقق يقرأ القيمة المختارة فعلًا وحالة الحقول والمرفقات وتغير القسم. هذا لا يثبت أن خادم التوظيف قبل الملف أو الطلب. بعض frameworks تحتاج أحداثًا موثوقة لا تستطيع JavaScript توليدها؛ CAPTCHA/OTP والتوقيعات والأسئلة غير المعروفة تبقى للمستخدم. يدعم المسار العام Shadow DOM المفتوح وcontenteditable وcombobox المبني على button وmetadata القياسية autocomplete. الأجزاء المغلقة والأحداث الموثوقة قد تحتاج تفاعل المتصفح المأذون.

راجع `docs/architecture.md` للعقود، و`docs/implementation-2026-10-26.md` لنطاق التحديث. تطوير Radar ومساعد لغوي واستئناف جلسة بعد إغلاق المتصفح توسعات لاحقة.

مرجع إجراءات الوكيل الوحيد: [عقد التشغيل والتحسن المستمر](docs/agent-contract.md). لا تنسخ خطواته إلى سجلات الخبرات أو دليل الشركات.
