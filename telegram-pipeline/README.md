# 📬 Telegram Jobs Pipeline — منظومة معالجة وظائف التليجرام

هذا المجلد مخصص لمعالجة وفرز إعلانات التدريب التعاوني والوظائف المستخرجة من قنوات التليجرام.

## 📁 محتويات المجلد:
* `raw-exports/`: المجلد المخصص لوضع ملفات المحادثات والرسائل المصدرة من التليجرام بصيغة HTML (`messages.html`).
* `extract-script.js`: سكربت لاستخراج بيانات الوظائف (اسم الشركة، المسمى، المدينة، المكافأة، المتطلبات، الروابط) وتحويلها إلى JSON.
* `telegram-jobs.html`: واجهة تصفح تفاعلية مزودة بفلاتر للبحث حسب المدينة، المكافأة، التخصص، والتاريخ.
* `telegram-browser.js`: المنطق البرمجي لواجهة التصفح والفلترة.
* `telegram-data.js`: البيانات المعالجة المعروضة داخل صفحة الويب.
* `style.css`: أنماط وتنسيق واجهة التصفح.

## 🚀 كيفية الاستخدام عند إضافة محادثات جديدة:
1. قم بتصدير محادثة أو رسائل القناة من التليجرام (Export Chat History بصيغة HTML).
2. ضع الملفات المصدرة في مجلد `raw-exports/`.
3. لتشغيل الاستخراج على ملف جديد، افتح الطرفية وشغّل:
   ```bash
   node extract-script.js raw-exports/messages.html
   ```
4. سيتم إنشاء ملف `new-jobs.json` بالفرص المستخرجة لتحديث `telegram-data.js`.
5. افتح `telegram-jobs.html` في المتصفح لتصفح الوظائف بالواجهة والفلاتر.
