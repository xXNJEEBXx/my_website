# 🚀 منظومة التقديم الذكي للتدريب التعاوني (Co-op Automation & Tracking)

مشروع متكامل لإدارة وأتمتة البحث والتقديم على فرص التدريب التعاوني (Co-op)، وتتبع الشركات، وتعبئة نماذج التوظيف تلقائياً.

---

## 📁 الهيكل التنظيمي للمشروع

```text
├── documents/                 # المستندات والشهادات الرسمية (الهوية، الجواز، السجل، الخطاب، الـ CV الرسمي)
├── assets/                    # وسائط البورتفوليو (الفيديو التعريفي، الصور، الأصول المرئية)
├── data/                      # بيانات التقديم والشركات المستهدفة
│   ├── current-applied-companies.json   # سجل التقديمات الجديدة للسمستر الحالي
│   ├── previous-applied-companies.json  # أرشيف 160 شركة تم التقديم عليها سابقاً
│   ├── local-companies-plan.md          # دليل وخطة التواصل مع شركات الأحساء والشرقية
│   └── tracker.js                       # محرك التتبع والبحث والفلترة الذكي (CLI)
├── cv-autofill-extension/     # إضافة كروم المخصصة لتعبئة نماذج التوظيف تلقائياً
├── telegram-pipeline/         # منظومة معالجة رسائل وقنوات التليجرام (سكربت الاستخراج، الواجهة، الفلاتر)
├── archive/                   # الأرشيف (السمستر الماضي + Simplify + Playwright)
│   ├── previous-semester/
│   ├── simplify/
│   └── custom-playwright-mcp/
├── .agent/                    # مسارات العمل الذكية وسجلات التعلم والبحث
│   ├── workflows/             # مسارات البحث وتصفية التليجرام
│   ├── agent-learnings.md     # سجل خبرات وحيل بوابات التوظيف
│   └── search-log.md          # سجل جولات البحث لمنع التكرار
├── index.html                 # موقع البورتفوليو الشخصي (GitHub Pages)
├── jobs-dashboard.html        # لوحة متابعة وتتبع فرص التدريب التعاوني (تفاعلية)
├── My CV.md                   # المرجع النصي الكامل لبيانات السيرة الذاتية وتعليمات الوكلاء
└── send-emails.js             # سكربت الإرسال الآلي لإيميلات التقديم المخصصة
```

---

## 🛠️ الأدوات الرئيسية وطريقة تشغيلها

### 1. إرسال الإيميلات آلياً (`send-emails.js`)
* يقوم بإرفاق السيرة الذاتية وخطاب الجامعة تلقائياً من مجلد `documents/`.
* لتجربة الإرسال الوهمي (Dry Run):
  ```bash
  node send-emails.js --dry-run
  ```

### 2. خط أنابيب التليجرام (`telegram-pipeline/`)
* عند تصدير محادثات جديدة من التليجرام بصيغة HTML:
  1. ضع الملفات في `telegram-pipeline/raw-exports/`.
  2. شغّل سكربت الاستخراج:
     ```bash
     cd telegram-pipeline
     node extract-script.js raw-exports/messages.html
     ```
  3. افتح `telegram-jobs.html` لتصفح الوظائف المستخرجة والفلترة بالمدينة والراتب.

### 3. إضافة كروم للتعبئة التلقائية (`cv-autofill-extension/`)
* تعمل الإضافة محلياً داخل المتصفح بدون الحاجة لأي خوادم:
  1. افتح صفحة `chrome://extensions` في متصفح كروم.
  2. فعّل وضع المطور (Developer Mode).
  3. اضغط على (Load unpacked) واختر مجلد `cv-autofill-extension`.
  4. عند فتح نموذج توظيف، تظهر خطة للمراجعة. شغّل التعبئة من لوحة الإضافة أو popup، وراجع نتائج التحقق.

### 4. محرك وأداة التتبع الذكية للوكيل (`data/tracker.js`)
* أداة CLI للوكيل للبحث والفلترة والإضافة الآمنة دون تعديل ملفات JSON يدوياً:
  ```bash
  # البحث عن الشركات ذات الرواتب العالية في الأرشيف أو الحالي
  node data/tracker.js search --high-salary --archive

  # البحث المفلتر في السعودية للفرص المعلقة
  node data/tracker.js search --region sa --status pending

  # تسجيل التقديم لشركة
  node data/tracker.js apply --company "اسم الشركة" --notes "تم التقديم بنجاح"

  # إحصائيات التقديم للسمستر الحالي
  node data/tracker.js stats
  ```

### 5. لوحة متابعة وتتبع الفرص (`jobs-dashboard.html`)
* واجهة تفاعلية متجاوبة تفتحها في أي متصفح لمتابعة تقديماتك:
  * التبديل بنقرة واحدة بين **السمستر الحالي** و **أرشيف 160 شركة سابقة**.
  * فلاتر فورية حسب الدول (السعودية، الخليج، أوروبا، أمريكا، آسيا، عن بعد).
  * فلتر الرواتب العالية والمجزية والبحث السريع.
  * تعديل وحفظ وتصدير البيانات مباشرة من المتصفح.

### 6. منظومة الاختبارات المعملية الشاملة للنماذج (`test-suite/`)
* **التشغيل الآلي عبر الـ CLI (أقل من نصف ثانية):**
  ```bash
  node test-suite/run-tests.js
  ```
  يشغّل اختبارات على كود المطابقة والبيانات الفعلي. لاختبار الإضافة المثبتة داخل Chrome شغّل أيضًا `node test-suite/browser-tests.cjs`؛ النماذج تُحمّل محليًا دون تقديم حي.
* **المختبر التفاعلي (`test-suite/sandbox.html`):**
  شغّل `node test-suite/serve.cjs` وافتح المختبر المحلي لمعاينة العينات وفحص حالتها مع الإضافة المثبتة. اختبارات المنصات الآلية في `browser-tests.cjs`.
* **فاحص ما قبل الإرسال (Pre-Flight Sanity Inspector):**
  تفحص الإضافة القيم المحددة والحقول والمرفقات المطلوبة قبل الإرسال عبر أدواتها. التعبئة لا ترسل الطلب النهائي؛ الإرسال إجراء صريح مستقل.

تفاصيل حلقة تعلم الإضافة والتحديث التلقائي: [عقد تشغيل الإضافة](cv-autofill-extension/docs/agent-contract.md) و[المراجعة الثانية](cv-autofill-extension/docs/second-review-2026-10-27.md).
