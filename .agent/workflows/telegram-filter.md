## 🎯 آلية الاستخراج والمعالجة (Extraction Criteria)

لا توجد كلمات مفتاحية للاستبعاد. المطلوب هو **استخراج جميع الوظائف وفرص التدريب** (التدريب التعاوني / الصيفي / المنتهي بالتوظيف) بالكامل **مهما كان التخصص أو المدينة** وإضافتها لحفظها في ملف `telegram-data.js`.

البيانات المستهدفة لكل فرصة:

- تاريخ النشر (Date) (موجود في رأس الرسالة في التيلجرام)
- اسم الشركة (Company)
- المسمى (Title)
- المدينة (Location)
- المكافأة (Salary)
- المتطلبات (Requirements)
- التاقات (Tags: مثل `#الرياض`, `#جدة`, `#هندسة`, `#أمن_سيبراني`, `#المكافأة_غير_مذكورة` الخ)
- الوصف (Description)
- روابط التقديم أو الإيميلات (Links)

---

## 🛠️ آلية الاستخراج المباشرة (Direct Script Extraction)

بدلاً من تقسيم الملفات يدوياً أو تفتيتها، يتم الاستخراج آلياً وبأمر واحد عبر السكربت المخصص:

1. **وضع الملفات:** ضع ملف التصدير (`messages.html`) داخل `telegram-pipeline/raw-exports/`.
2. **تشغيل سكربت الاستخراج:**
   ```bash
   cd telegram-pipeline
   node extract-script.js raw-exports/messages.html
   ```
4. **الاستيراد من النصوص وملخصات التليجرام (`telgrm new.md`):**
   - عند توفر إعلانات بصيغة نصوص ملخصة أو Markdown:
     1. استخرج اسم الشركة، المدينة، والمجال.
     2. أضف الشركة فوراً إلى لوحة التتبع عبر أداة التراكر:
        ```bash
        node data/tracker.js add --name "الاسم" --city "المدينة" --role "الدور" --competitive --notes "..."
        ```
     3. إذا كان الرابط مفقوداً في نص الإعلان (مثل `للتقديم____`):
        - استخدم أدوات البحث (`search_web`) للعثور على بوابة التقديم الرسمية.
        - حدّث رابط الشركة في التراكر:
          ```bash
          node data/tracker.js update --company "الاسم" --link "https://..."
          ```
